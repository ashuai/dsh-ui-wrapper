# v0.1.2

- 新增:**后端自动拉起** —— 启动探测 `127.0.0.1:3080`,不通则按 `bunx → pnpm → npm → dsh` 自动启动 dsh web;真机验证:停掉后端后打开 App,约 1 秒内拉起并载入,关闭窗口后端保持常驻
- 新增:**自举页** —— 大胖鲸 logo(base64 内嵌)、toast 进度提示(`打开中…` / `启动中… 已等待 Ns` / `已就绪` / `启动失败`)、错误面板(后端日志尾部 + 重试按钮,IPC 驱动)
- 新增:**快速失败** —— 拉起进程提前退出(端口被占/缺依赖)约 0.4s 即报错,不等超时;总超时默认 30s(`DSH_BACKEND_TIMEOUT` 可调)
- 新增:**自适应深浅色** —— 启动页跟随系统外观(`prefers-color-scheme`),不再硬编码深色
- 新增:**跨平台启动器发现** —— 按 OS 分支(macOS/Linux 执行位 + 兜底目录;Windows 试 `.exe/.cmd/.bat`、`;` 分隔 PATH、`%ProgramFiles%\nodejs` 等),Windows 目标 `cargo check` 通过
- 新增:**PATH 兜底** —— Finder 双击启动也能找到 Homebrew 的 bunx(spawn 时补全 PATH)
- 新环境变量:`DSH_URL` / `DSH_NO_AUTOSTART` / `DSH_BACKEND_TIMEOUT` / `DSH_BACKEND_LOG`
- 文档:README 重写为默认英文 + 新增中文版(`README.zh.md`)
