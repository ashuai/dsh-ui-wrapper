# v0.1.3

- 新增:**macOS 主菜单** —— App(⌘Q 退出)+ Edit(Undo ⌘Z / Redo ⇧⌘Z / Cut ⌘X / Copy ⌘C / Paste ⌘V / Select All ⌘A),快捷键与菜单项均可用
- 新增:**右键菜单接管** —— 只保留 Cut / Copy / Paste,WebKit 默认菜单(查询词典、翻译、网页搜索、拼写与语法、刷新、分享、Speech、Play All Animations、Services 等)全部移除
- 修复:**菜单项 action 失效** —— `sel!` 宏误用变量导致生成假选择器 `sel`,改用 `Sel::register` 运行时注册真实选择器
- 修复:**按键崩溃** —— 菜单项直接 target WKWebView 会触发 WebKit `doneWithKeyEvent` 回调链 panic → abort;改回响应链(nil target)+ 窗口聚焦时确保 WKWebView 为首响应者
- 新增:**常驻 panic 日志** `~/Library/Logs/DSH-panic.log` —— 不依赖 DSH_DEBUG,任何崩溃都会留下 panic 消息与回溯,便于排查
- 工程:CI 动作升级到 Node 24 大版本(`checkout@v7` / `upload-artifact@v7` / `download-artifact@v8`),消除 node20 弃用告警
